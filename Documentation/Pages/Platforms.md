@page page_platforms Platforms

## Primary support tier

- ✅ macOS 13.6+ (Ventura) and iOS 14.0+
- ✅ Windows (10+)
- ✅ Linux (Kernel 5.x+)

## Experimental support tier

- 🧪 NetBSD 11
- 🧪 FreeBSD 15.1
- 🧪 OpenBSD 8.0

The BSD ports run the shared Debug and Release suite on amd64 and ARM64, but remain a lower support tier than macOS,
Windows, and Linux. Support is tied to the listed releases and tested capabilities; compatibility with other BSD
systems or releases is not implied. See the [BSD support matrix](@ref page_build) for the verified scope and limits.
